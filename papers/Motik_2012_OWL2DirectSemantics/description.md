Defines the direct model-theoretic semantics and inference problems for OWL 2. Object-property characteristics constrain binary relations within a satisfied ontology, while consistency, entailment, subsumption, instance checking, and query answering are explicit reasoning operations. This confirms that Propstore's test-only relation declarations have no production semantics to wire in.
