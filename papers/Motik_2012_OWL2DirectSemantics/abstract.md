# Abstract

## Original Text (Verbatim)

The OWL 2 Web Ontology Language, informally OWL 2, is an ontology language for the Semantic Web with formally defined meaning. OWL 2 ontologies provide classes, properties, individuals, and data values and are stored as Semantic Web documents. OWL 2 ontologies can be used along with information written in RDF, and OWL 2 ontologies themselves are primarily exchanged as RDF documents. The OWL 2 Document Overview describes the overall state of OWL 2, and should be read before other OWL 2 documents. This document provides the direct model-theoretic semantics for OWL 2, which is compatible with the description logic SROIQ. Furthermore, this document defines the most common inference problems for OWL 2.

## Our Interpretation

OWL 2 gives relation properties meaning through a complete ontology interpretation and defines the exact inference questions that a consumer may ask. A declaration without authored ontology persistence, axiom closure, and a reasoning consumer is not an integrated semantic capability.
