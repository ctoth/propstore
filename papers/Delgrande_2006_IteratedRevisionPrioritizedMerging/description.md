Recasts iterated revision in a static world as prioritized merging of explicit observations whose reliability levels need not follow recency. It gives a principled home for source-reliability information: typed observations and an explicit prioritized merge operator. This supports deleting Propstore's test-only entrenchment override map while preserving source provenance for a future, separately owned reliability-and-merging capability.
