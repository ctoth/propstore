Defines the SROIQ description logic and its ontology-wide semantics for relation characteristics, complex role inclusions, and role assertions. For Propstore, it shows that a real relation-property capability needs persisted authored axioms, global admissibility restrictions, and a reasoner. The test-only relation kernel supplies none of these and should not be treated as a partially integrated SROIQ subsystem.
