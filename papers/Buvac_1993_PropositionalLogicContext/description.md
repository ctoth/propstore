Defines a propositional logic of context with the modality ist(κ, φ), per-context partial vocabularies (Bochvar three-valued satisfaction), nested context sequences with no outermost context, and ist read as validity over a set of truth assignments, with a Hilbert system (PL, K, Δ+, Δ−, MP, CS). Proves soundness and completeness via a CNF lemma and canonical model, and gives correspondence results for consistent contexts (D), flat contexts (Fl+, Fl−), ist-as-truth (Tr), and a meaninglessness-as-falsity variant (MF) modelling Guha's reading. Provides the formal propositional base for propstore's first-class ist(c, p) contexts and for deciding whether an out-of-vocabulary claim is meaningless or false in a context.
