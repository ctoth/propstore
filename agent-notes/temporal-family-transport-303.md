## Decisions and why
- Smallest change: two typed family identity functions (~40 lines) and two registered callbacks (~25 lines), contract metadata update, production-path regressions. Existing Quire mapping, validation and path collision owner remain unchanged; no merge algorithm rewrite.
- Exact identity law: anchor content key `(claim_id, frame_id, valid_from, valid_until)`; edge content key `(earlier_claim_id, later_claim_id, account)`. Hash canonical JSON with Quire's existing primitive and distinct family namespace. These are the complete authored temporal semantic fields. Bounds and account are never inferred/defaulted; endpoints remain ordered. Reidentity abstracts the old self id and is independent of merge/branch history. Quire calls it only if a declared FK changed; unchanged nominal ids and file reads remain intact.
- Provenance is excluded by its explicit owner contract (`propstore/provenance/__init__.py`, `Provenance` docstring). An initial thought to hash the whole evidence document was rejected before any code: that would violate this contract. All provenance fields remain in stored output. Equal identities with unequal full documents must fail through existing collision admission; do not merge/drop evidence.
- Coreference excluded: existing `derive_coreference_argument_id` hashes supports, but `attacks` has no declared FK despite pointing to argument ids. A callback alone would leave references to reidentified arguments stale. Resolving this self-referential relation is a separate bounded slice.
- Active cleanup-refactor control surface: temporal family slice. Charters/repositories are typed domain and IO owners (keep); missing identity operation is valid capability in the domain family identity owner (create there; wire directly). Forbidden: temporal dispatch in merge, duplicate FK tables/parsers, loose semantic dictionaries across runtime, fallback readers, codec changes. No wrong production file/surface needs deletion. Existing unsupported-temporal test scaffolding will be replaced by successful production paths while coreference rejection remains.
