## Decisions and why
- Smallest implementation: ~60 generic lines in Quire to plan one explicit finite batch's affected IDs using existing family callback and declared self-reference graph, then replay ordinary validated atomic reference transport with the complete image map. No hash fixed point or iteration limit. An identity depending incompatibly on rewritten self-references fails existing single-image enforcement rather than inventing a policy. Non-self-referencing families use their existing one-row operation directly.
- Propstore: declare `attacks[]` as FK into `proposal_coreference.argument_id`, register callback reusing existing `derive_coreference_argument_id(supports)`, and pass each pinned parent's family batch to the generic owner. No attack inference, filtering, Cartesian copying or new identity law.
- Closure includes legacy nominal-ID attackers whose own supports did not move but whose target did. Their changed references require the existing family identity operation; all affected IDs are planned before final rewrites. Unaffected legacy records retain original identity and placement. Same final ID with unequal descriptions, attack sets, provenance or note must reject through existing admission; no evidence loss.
- A canonical attacker with unchanged supports may map to the same ID in both parents while its attack target maps differently. Its two output documents then genuinely conflict under the established support-only identity. Preserve/reject this conflict, never combine attack sets or invent branch/hash identities. Dedicated production regression is written but not yet reached successfully because of fixture setup failure.
- Active cleanup-refactor: existing typed family/repository/identity/AF owners keep their surfaces. Missing FK is omitted schema wiring (extend charter); one-row dependency edge is a valid generic capability needing explicit finite-batch operation at Quire (extend true owner, rewrite caller). No wrong production file to delete. Forbidden: Propstore FK graph/parser/preassignment mechanism, recursive hash, hash of attack targets, fallback reads, attack dropping, concurrency rewrite. Preserve old temporal and path collision behavior.
